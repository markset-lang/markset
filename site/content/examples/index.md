# Examples

{.lead}
Complete documents, not fragments. Each one is a real `.md` file in the repository, parsed and rendered for this site by the same packages the command line uses.

Each one is read with a theme stylesheet of its own, and none of them names a color or a width in its source. Everything categorical — a status chip, a tinted pipeline stage, an alert banner, a drawing sheet — is an author class that the theme interprets. That is what keeps a document portable: paste it anywhere and it still reads, because a renderer that has never seen those classes simply ignores them.
