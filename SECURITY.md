# Security

Please report a vulnerability privately to **security@coralreefventures.com**, not in a public issue or pull request.

Say what you found, how to reproduce it, and the version or commit you saw it in. We will acknowledge your report,
keep you informed while we work on it, and credit you when the fix is released unless you would rather we did not.

This repository is maintained by Coral Reef Ventures, LLC. For anything that is not a security report, write to
hello@coralreefventures.com.
