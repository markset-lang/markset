## Short

Markset is Markdown with a small, closed vocabulary of layout constructs: cards, grids, columns, tabs, steps, metrics, figures, callouts. Every Markdown file is already a valid Markset document. We publish the specification, the reference implementation, and the tools that put it in your editor.

## Long

Markset extends Markdown with a small, closed vocabulary of layout constructs — cards, grids, columns, tabs, steps, metrics, figures, and callouts — and nothing else. It is a strict superset of CommonMark: every Markdown file you already have is a valid Markset document, and every Markset document still reads as plain Markdown wherever the layout cannot follow. Authors name what a thing is; a stylesheet decides how it looks, so a document carries no colors, no widths, and no scripts. The vocabulary is fixed and every construct is pinned by a public conformance suite, so tools agree on what a document means. We publish the specification, the reference implementation, and the editor tooling. Specification and playground at markset.org.
